# phonton-cli v0.21.1

## Cost receipt on the serve line

`GlobalState` and `HandoffPacket` now carry a `CostReceipt`: actual spend, a labeled frontier counterfactual, saved micros, and the cheap-first route. Desktop and `phonton review` read the same fields from `goal.status` / `review.get`.

## Fail-closed dispatch

- Escalation uses per-tier model ids. A configured cheap model is not reused as Standard or Frontier.
- Missing provider keys fail before a stub diff can be treated as verified success. Run `phonton doctor --provider` first.
- Local-template seeds match the subtask after a memory preamble. A failed seed falls through to the configured provider.

## TUI

The savings line reports spend vs frontier when a receipt is present.

## Golden path

`fixtures/add-one` is a one-test Cargo crate. `example-receipt.json` is a labeled live receipt, not a competitor comparison.
