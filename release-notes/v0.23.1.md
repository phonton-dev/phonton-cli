# phonton-cli v0.23.1 — Receipts that agree

A small polish release found while re-recording the README demo on 0.23.0.

## One place for tokens and cost

A finished run's TUI receipt already lists tokens in, tokens out and API
cost. A second line under it repeated the cost and counted tokens from a
different source, so a run could show 803 in + 1,558 out in the receipt and
2,362 tokens a few lines below. That line now shows only while a goal runs.
For models with a listed price, the "vs frontier" estimate moved into the
receipt; unpriced and local models get none, as before.

## Fewer non-gaps

"No application launch command was inferred" is no longer listed under
Known gaps. A library has no launch command, so the line appeared on almost
every run without telling you anything. Run commands are still listed when
Phonton infers some.

## Fresh README demo

The README hero and demo GIF are a new recording of this release (DeepSeek
Flash on a small JavaScript repo). The previous ones came from 0.22.0 and
still showed the "saved 100% vs Σ 35000" line that 0.22.3 removed.

## Install

```bash
npm install -g phonton-cli
phonton version    # phonton 0.23.1
```
